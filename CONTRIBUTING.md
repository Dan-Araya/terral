# Contribuir

Para empezar, ejecuta la demo y las pruebas del README. Los cambios de presentación deben conservar el contrato de la API y la procedencia de las fechas. No cambies los modelos congelados para modificar el aspecto de una probabilidad.

Describe el problema, el cambio y cómo lo comprobaste. Las pruebas públicas deben funcionar sin red, sin datos privados y sin tareas programadas. Usa entradas sintéticas para los casos nuevos.

Antes de publicar archivos, revisa `publicacion.json` y [las reglas de datos](docs/datos.md). Las observaciones, respaldos, tokens y archivos de entorno quedan fuera del repositorio. No incluyas credenciales o datos personales en incidencias o pull requests.

Un cambio científico debe distinguir evaluación retrospectiva y servicio actual, documentar el soporte temporal y evitar utilizar el período reservado sin un protocolo explícito.
